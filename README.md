# HuellaMYPE

Historial verificable para MYPE que venden al Estado. Public procurement open data (OECE / SEACE, OCDS, CC BY 4.0) becomes a per-supplier "huella" document; its hash is attested on Stellar testnet by a Soroban contract, the MYPE claims it with its own Stellar account, and any lender verifies it in the browser without trusting our server. No personal data on-chain.

Built for Stellar Codember Perú 2026.
