# What the hackathon is
A hybrid three-week buildathon organised by the Stellar Ambassador Program in Peru with the Blockchain Acceleration Foundation. Teams of 1–4 build a working application on Stellar **testnet** that solves a real problem. Free theme, one category. Prizes: US$300 / 200 / 100 in XLM. Sources: https://stellar.mintedinpe.com/codember/bases and the APEX page https://stellarapex.org/hackathons/85928156-bffb-41f0-9066-2a221614c01a (one track "General", criteria scored 0–5).

Relevant suggested lines for us: **Inclusión financiera** (microcredit) and **Identidad y credenciales** (verifiable certificates, reputation).

# Technical requirements
- Interact with Stellar testnet (Soroban contract or SDK/RPC/Horizon) and be deployed; give contract ID/addresses with an explorer link.
- Public GitHub repo **with commit history during the period**.
- Third-party code, templates and prior code allowed **only if declared in the README**.
- Not eligible: projects that already won a hackathon or got Instaward/SCF funding.
- Excluded: speculation, gambling, promised returns, speculative tokens.

# Deliverables (APEX)
1. Repo link. 2. README with problem, solution, architecture, how to run, contract ID/addresses, team, **AI usage and prior code**. 3. Video ≤ 3 min, open access, product working + problem explained. 4. Deployed app link.

# Judging
| Criterion | Weight |
|---|---|
| Uso de Stellar — contratos, pagos, activos y cuentas | 25 |
| Funcionalidad y calidad técnica — funciona en testnet, código ordenado y documentado | 25 |
| Problema e impacto — relevancia y claridad del usuario objetivo | 20 |
| Innovación — originalidad de la propuesta o del enfoque | 15 |
| Presentación y UX — claridad del video y facilidad de uso | 15 |
Jury evaluates repo, testnet deployment and video only. Ties and void places at jury discretion; decisions final.

# Other rules
Eligibility: 18+, one team per person, at least one Peruvian/resident member. Team keeps IP (MIT recommended). Prizes paid in XLM to a verified recipient chosen by the team. Disqualification: plagiarism or undeclared prior work, false data, ineligible project.
